使用说明:
1. 模拟模式: python run_example.py
2. API模式: 在model_manager.py中设置API Key
3. 完整运行: python main.py --project my_story --concept '故事概念'

提示词配置:
- 默认模板在prompt_config.py中
- 可自定义模板并保存到prompt_configs文件夹
- 支持JSON格式的模板导入导出

模型调用:
- 支持真实API调用(需要API Key)
- 支持模拟模式(无API Key时)
- 可配置模型参数和超时时间
